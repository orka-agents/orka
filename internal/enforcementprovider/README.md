# Enforcement providers

This package authenticates provider descriptors, preserves exact policy bytes, verifies signed activation/readback proof, and keeps a workload held until proof consumption and its release obligation are committed atomically. Providers implement prepare, activate, independent readback, proof, release, status, reconciliation, and cleanup. The signed protocol uses versioned length-framed transcripts and binds the complete authorization. Durable cleanup retains replay-safe tombstones. File-backed controllers bind state to one absolute path, reject hard-link aliases, have exclusive lifetime ownership, and must be closed. Policy contents remain provider-owned opaque bytes; Orka validates only generic bounds, digest, and capabilities.
