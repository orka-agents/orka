# Orka UI

React + TypeScript single-page app for the Orka controller, built with Vite,
TanStack Router/Query, Tailwind, and Vitest. The production build is embedded
into the controller binary (`make ui-build` from the repository root copies it
into `internal/uiembed/dist/`).

## Commands

```bash
bun install          # install dependencies
bun run dev          # dev server on :5173, proxies /api to localhost:8080
bun run lint         # eslint
bun run test         # vitest unit tests
bun run build        # type-check (tsc -b) and production build
```

Run `bun run build` after edits: it type-checks against the library target,
which `vitest` and `eslint` do not.

## Layout

- `src/routes/` — file-based routes. `src/routeTree.gen.ts` is generated by the
  TanStack Router Vite plugin; do not edit it by hand.
- `src/components/` — feature components (`tasks/`, `sessions/`, `gateways/`,
  ...) and shared primitives under `ui/`.
- `src/hooks/` — TanStack Query hooks over the `/api/v1` client.
- `src/schemas/` — zod schemas for API payloads.
- `src/lib/` — framework-free helpers (API client, list pagination, time
  formatting).
