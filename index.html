Open source · MIT · Kubernetes-native

Run AI agents and coding agents on your cluster. Model keys never leave it.

Describe work as a Task. Orka runs it in a Pod, keeps a durable record of what happened, and hands you the result through an API, a CLI, or the built-in dashboard. One Helm command to install.

Get startedTry the dashboardWatch demos
Install
$ helm repo add orka https://orka-agents.github.io/orka/charts
$ helm repo update orka
$ helm install orka orka/orka -n orka-system --create-namespace --wait --timeout 10m

Live view

Every agent runs as a Task you can watch.

Each Task runs in a Pod and reports its phase. Consequential actions wait for a person, and every step is kept in a durable record.

Example Task timeline: checkout-latency-investigation-7k2qp (AI) moves from Pending to Running, requests approval to roll back checkout-service in production to v3.18.2, receives approval, and succeeds. fix-cart-rounding-bug-x9m4d and review-pr-1482-q8m4d (agents), and terraform-drift-check-u5r1a (container), each move from Pending to Running to Succeeded. release-v2-14-0-notes-h4t6n (agent) moves from Pending to Running and is still running when the example ends. The terminal shows the same phase changes as kubectl get tasks -w, with columns for name, type, phase, priority, and age.

Quick start

From an empty cluster to a coding agent reviewing a real repository.

  1. 1

    Install with Helm

    One Helm command. The chart creates its namespaces, its encryption key, and its webhook certificate. Works on kind or minikube. No model API key needed yet.

    Install Orka
  2. 2

    Run your first AI task

    Connect to the API, add your Anthropic, OpenAI, or Azure OpenAI key as a Provider, and submit a Task.

    Run your first task
  3. 3

    Run a coding agent

    Connect your model gateway and let Codex or Claude Code review a repository from a warm pool.

    Run a coding agent

What you can do

One install covers AI tasks, coding agents, repository automation, and the ways people reach them.

Coding agents that open PRs

Codex, Claude Code, Copilot CLI, and OpenCode work on a clean checkout. A separate publisher pushes the verified change and opens the pull request.

Read more

AI tasks with tools

Anthropic, OpenAI, or Azure OpenAI models with web search, code execution, custom HTTP and MCP tools, skills, and sessions.

Read more

Multi-agent coordination

Coordinators delegate to specialists within allowlist, depth, and concurrency limits, or work toward a goal autonomously.

Read more

Issue to pull request

Review every pull request, or label an issue and let agents plan, implement, repair, and mark it ready to merge.

Read more

Repository security scanning

Threat models, validated findings, and remediation pull requests, with a person choosing what gets fixed.

Read more

Chat, dashboard, and CLI

Describe work in plain language to an orchestrator, watch it live in the dashboard, or script it with the orka CLI.

Read more

OpenAI & Anthropic APIs

Point Claude Code, Cursor, or Continue at Orka. People get a cluster token; nobody needs a provider key.

Read more

Teams, Telegram, and A2A

Gateways bring agents into the conversations people and other agents already have, with durable, deduplicated delivery.

Read more

Approvals and governance

Hold consequential actions for a person, let people act through their own linked accounts, and audit every Task.

Read more

Providers & runtimes

Bring your own models and coding agents.

Orka keeps the credentials in the cluster and gives them a common API.

  • AnthropicClaude models through the Provider CRD and an Anthropic-compatible Messages API.
  • OpenAIGPT models behind an OpenAI-compatible chat completions endpoint.
  • Azure OpenAIEnterprise OpenAI deployments running on Azure.
  • ACP RuntimePoolsRun Codex, OpenCode, Claude, and Copilot in digest-pinned, scale-to-zero RuntimePools with brokered tools and clean-room delivery.
