For operators:

  CRD lifecycle:
    - A fresh install creates Orka's cluster-scoped CRDs unless --skip-crds is used.
    - Helm does not update CRDs during helm upgrade. Apply the CRDs from the exact
      target chart before upgrading the release.
    - helm uninstall retains the CRDs and all Orka custom resources.

  Upgrade guidance: helm show readme <the same chart reference or archive>

  Gateway CRDs:
    Before enabling gateways on an existing installation, update the Task and
    Gateway CRDs from the exact target chart using the matching source checkout's
    scripts/apply-helm-crds.sh. See the README's Upgrading link for supported
    upgrade paths and the full procedure. The controller remains gateway-disabled
    until all three Gateway CRDs and the Task session-cutoff schema are observed.
